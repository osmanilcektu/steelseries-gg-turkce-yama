# Contributing to SteelSeries GG Türkçe Yama

SteelSeries GG Türkçe Yama projesine katkıda bulunmak istediğiniz için teşekkürler.

Bu proje topluluk katkılarına açıktır. Eksik veya hatalı çeviriler, yeni SteelSeries GG sürümleriyle gelen metinler, dokümantasyon geliştirmeleri ve uyumluluk düzeltmeleri için katkıda bulunabilirsiniz.

## Katkı Türleri

Aşağıdaki konularda katkılar kabul edilir:

- Eksik çevirilerin tamamlanması
- Hatalı çevirilerin düzeltilmesi
- Daha anlaşılır Türkçe karşılıkların önerilmesi
- Yeni SteelSeries GG sürümlerinin kontrol edilmesi
- Yeni çeviri anahtarlarının eklenmesi
- Kurulum dokümantasyonunun geliştirilmesi
- Uyumluluk sorunlarının giderilmesi
- README ve diğer dokümantasyonların geliştirilmesi
- Hata raporlarının doğrulanması

## Hata veya Çeviri Sorunu Bildirme

Küçük bir sorun için doğrudan Pull Request göndermek zorunda değilsiniz.

GitHub Issues üzerinden bildirim oluşturabilirsiniz:

https://github.com/osmanilcektu/steelseries-gg-turkce-yama/issues

Mümkünse şu bilgileri ekleyin:

- SteelSeries GG sürümü
- Türkçe yama sürümü
- Sorunun görüldüğü bölüm
- Mevcut metin
- Önerilen metin
- Ekran görüntüsü
- Sorunun nasıl tekrarlandığı

## Pull Request Gönderme

1. Repository'yi fork edin.
2. Fork'unuzu bilgisayarınıza klonlayın.
3. Değişikliğiniz için yeni bir branch oluşturun.
4. Değişikliklerinizi yapın.
5. Mümkünse değişiklikleri SteelSeries GG üzerinde test edin.
6. Açıklayıcı bir commit oluşturun.
7. Branch'inizi GitHub'a push edin.
8. Bu repository'ye Pull Request gönderin.

Örnek branch isimleri:

```text
fix/sonar-translation
translation/engine-update
docs/install-guide
